零、先说我是什么样的人

建筑工程出身，不是科班。所以我的路子和科班不同：

  • 带着问题去学技术，不是先学理论再找用途
  • 每个东西都是为了解决一个真实麻烦，不是练手
  • 习惯一个人把整条链走完：需求 → 设计 → 编码 → 部署 → 运维 → 出问题自己修

结果是：单点深度不如专职的人（不如专职前端做设计，不如算法工程师写算法），但端到端的完整能力极稀缺。一个产品从零到上线，绝大多数人只负责其中一段。

规模证据： - AI 短剧工坊：64,752 行 Python、2,484 路由、626 模板、32 表、11 生产步骤 - 炜达云微信小程序：45 个页面、14 个业务模块、飞书→微信全量迁移 - 210 个可复用技能（每个对应一个真实项目或踩过的坑） - 21 个生产故障完整复盘（公开在 GitHub）

领域 2｜后端工程

做过：2,484 个路由的 API 体系、32 张表设计、SQLite→PostgreSQL 迁移、多 worker 任务队列（SELECT FOR UPDATE SKIP LOCKED）、双登录认证（密码+短信）、CSRF 防护、X-Accel-Redirect 文件服务（区分管理员/普通用户权限）。

四个能脱稿讲的真实故障：

  1. 进度永远 0% — gunicorn -w 4 四进程各自内存字典，任务建在 #2，轮询进 #3 查不到。改落数据库，顺带解决重启丢状态。
  2. 限流失效 — 内存计数器 4 进程各算各的，配 100 次/分实际放行 400 次。
  3. 支付回调 302 — NOTIFY_URL 多写 blueprint 前缀，微信跳转丢 POST body。
  4. 时区错乱 — UTC 与本地时间混在一张表，同一天记录差一天。

领域 3｜AI 模型部署与调优

单卡 24G 跑通的：

类型 模型 实测
画图 FLUX.1 dev fp8 + IP-Adapter + ControlNet 20–40 秒/张
图生视频 Wan 2.1 / SVD 512p 短片段，第 2 秒易崩脸
口型 Sonic / LatentSync / Wav2Lip 4.8 秒音频跑 205 秒
语音合成 IndexTTS（154 音色+克隆）/ CosyVoice 常驻 6.7G
语音识别 whisper.cpp（CUDA 自编译） 中文优先，常驻 2.3G
文本 llama.cpp / vLLM，27B/32B 量化下沉

核心经验： - 显存不够不报 OOM，而是慢十倍然后给废图（在搬权重不是算） - 可用显存 = 单卡 − 常驻（我机器常驻 15G，24G 卡实际只有 9G） - 权重 ≤ 可用 × 0.8 才安全 - 双卡 ≠ 双倍显存（除非做 tensor parallel） - RTX 5090 需要新 CUDA，老框架直接编译失败

领域 11｜服务器运维与部署

  • Linux：无图形界面服务器全套配置
  • 服务托管：systemd（自动重启/日志/依赖顺序）
  • 反代：nginx/Caddy、子路径挂载、SSL、X-Accel-Redirect
  • 穿透：Cloudflare Tunnel、SSH 反向隧道、Tailscale 组网
  • 容器：Docker Compose 多服务（Chatwoot 五容器）
  • 六层排查法：进程 → 端口 → 反代 → 日志 → 数据库 → 外部 API

案例：家宽无公网 IP 打通外网访问并配 HTTPS；云服务器 443 被封改 SSH 反向隧道；无显示器服务器装 Windows VM。

领域 12｜消息机器人与多 Bot 运维

  • 8 个飞书 Bot 实例（feishu_1/2/3/4/17/18/21 + wb_1）独立 profile、systemd 托管、Docker 沙箱、掉线自恢复
  • 企业微信接入：AI Bot 长连接模式，扫码登录、凭据加密
  • 邮箱自动化：IMAP 读取、规则过滤、4 小时定时巡检
  • 定时任务体系：cron 管理、失败告警、避免重复执行

踩过的坑：gateway 进程内重启自己会自杀 → 用一次性 cron 脱离进程树；多实例必须 gateway.standalone: true；沙箱的技能目录是软链，rm -rf 删到真身（踩过 3 次）。

领域 13｜支付与商业化闭环

  • 微信支付 v3：Native 扫码、签名验证、回调验签、AES-GCM 解密
  • 积分计费：扣费规则单一真相源（DB 驱动）、步骤单价可配
  • 订单退款：实付/赠送分离追踪、退款上限校验
  • 充值流程：下单→支付→回调→到账→赠送，全链路幂等

三个坑：NOTIFY_URL 多前缀→302；公钥不匹配→401；APIv3 密钥不匹配→AES 解密失败。

领域 14｜浏览器自动化与逆向

  • Playwright 全自动发布：掘金 + CSDN 全流程（今天跑通）
  • CDP 接管模式：用户扫码，程序控制同一窗口，不碰密码验证码
  • 绕 WAF：识别无头指纹 → 改有头（Xvfb）
  • 逆向工具链：jadx / apktool / Ghidra 12.2 / radare2 / frida / mitmproxy
  • 爬虫：招标公告、企业信息、视频数据

关键经验：curl 通但浏览器 403 = 指纹问题不是 IP；JS .click() 不触发框架事件委托，必须真鼠标；点不动的按钮先抓服务端错误，别瞎试 UI。
